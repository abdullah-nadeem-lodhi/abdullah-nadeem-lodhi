# Icons

This project uses [skillicons.dev](https://skillicons.dev) to render the tech-stack badges directly
in `README.md`, so no local icon files are required — the icons are fetched live and stay
up to date automatically.

If you'd rather self-host icons (e.g. for offline builds or a personal site version of this
profile), drop SVG/PNG assets in this folder and reference them with relative paths instead:

```md
![React](./assets/icons/react.svg)
```
